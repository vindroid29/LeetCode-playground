# Leet-Code-playground
A curated collection of LeetCode data structures and algorithms problems solved efficiently in Kotlin, complete with unit tests and complexity analysis.
# 🚀 LeetCode Solutions in Kotlin

A clean, well-structured repository containing my personal solutions to various LeetCode algorithmic and data structure problems, written entirely in Kotlin.

## 📌 Project Features
*   **100% Kotlin**: Leveraging modern Kotlin features (idiomatic collections, scope functions, extension methods).
*   **Unit Tested**: Problems include JUnit tests to verify correctness and edge cases.
*   **Complexity Analysis**: Time and space complexities are documented for every solution.
*   **Clean Architecture**: Structured systematically by problem difficulty and topic.

## 🛠️ Project Structure
The project is organized by LeetCode problem difficulty and topics for easy navigation:

```
leetcode-kotlin/
├── .gitignore
├── build.gradle.kts
├── settings.gradle.kts

├── gradlew.bat
├── gradle/

├── main/

│               ├── medium/

``

## 💻 Tech Stack
*   **Language:** Kotlin 2.x
*   **Build Tool:** Gradle (Kotlin DSL)
*   **Testing:** JUnit 5

## 🏃 How to Run Tests
To run all problem test cases locally, use the following Gradle command:
```bash
./gradlew test
```
